## 7. Data Security

### 7.1 Technical Measures
- **Encryption**: TLS 1.3 in transit; AES-256 at rest (database)
- **Authentication**: JWE (JSON Web Encryption) tokens, bcrypt password hashing (cost 10)
- **Access Control**: Role-based (user/shopkeeper/admin), token-based API auth
- **Database**: Parameterized queries, prepared statements (SQL injection prevention)
- **Rate Limiting**: API rate limits, brute-force protection
- **Input Sanitization**: XSS/injection prevention on all inputs

### 7.2 Organizational Measures
- Need-to-know access for staff
- Regular security reviews
- Incident response plan
- Staff privacy training

### 7.3 Limitations
No internet transmission or storage is 100% secure. We cannot guarantee absolute security.
